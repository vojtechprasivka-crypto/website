# AI Recepční - Landing Page

Moderní konverzní web pro AI agenturu nabízející AI recepční služby v Česku.

## Technologie

- **React** - UI framework
- **Vite** - Build tool
- **Lucide React** - Ikony
- **CSS3** - Moderní styling s glassmorphism efekty

## Instalace a spuštění

### 1. Nainstalujte závislosti

```bash
npm install
```

### 2. Spusťte vývojový server

```bash
npm run dev
```

Web bude dostupný na `http://localhost:5173`

### 3. Produkční build

```bash
npm run build
```

## Funkce webu

✅ **Moderní UI** - Glassmorphism, gradienty, animace  
✅ **Konverzní design** - CTA tlačítka, lead formulář, důvěryhodnostní prvky  
✅ **Český jazyk** - Kompletně v češtině  
✅ **Responzivní** - Optimalizováno pro mobil, tablet i desktop  
✅ **SEO ready** - Meta tagy, sémantické HTML  

## Struktur sekce

1. **Hero** - Hlavní nabídka s ukázkou AI hovoru
2. **Benefity** - Klíčové výhody služby
3. **Funkce** - 4 hlavní funkce AI recepční
4. **Proces** - 3 kroky nasazení
5. **Cena** - Pilotní nabídka
6. **Kontakt** - Lead formulář

## Customizace

Upravte obsah v `src/App.jsx` a styling v `src/styles.css`.
